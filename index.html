    About Clann MAG Explorer

    Clann MAG Explorer is a free, open-source tool for exploring and manually refining metagenome-assembled genome (MAG) binning results. It does not run a binning algorithm itself — it takes an assembly and one or more binning tools' independent contig-to-bin assignments, computes per-contig statistics directly from the sequences, and gives you an interactive way to see where those tools agree, where they disagree, and to manually reassign contigs in response.

    This is under active development — see the repository for current status.

    Supported input sources

    • Assembly — a contig FASTA (.fasta/.fa/.fna, optionally gzip-compressed), source of every per-contig statistic.
    • Contig→bin table (one or more) — a two-column tab/CSV file per binning tool, contig ID and bin ID.
    • Coverage depth table — contig ID plus one depth column per sample.
    • Kraken2 report — per-contig taxonomic call, reusing Clann eDNA Explorer's report parser.

    Every format is identified by file content, not filename or extension.
